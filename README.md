
# Hastings Kholola | Personal Portfolio Website

## About the Project

This portfolio website showcases the profile of Hastings Kholola, a Computer Science student with interests in website development, WordPress customization, graphic design, and networking. The website is designed to present his skills, academic background, and professional interests in a modern and visually appealing way.

## Purpose

The site acts as a digital portfolio and contact page for:

- Website development
- WordPress website creation and customization
- Graphic design using CorelDRAW
- Networking and digital communication support

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Visual Studio Code
- Git and GitHub

## Pages

1. Home - Personal introduction and main profile overview
2. About Me - Academic background, skills, interests, and goals
3. Projects - Service and expertise showcase
4. Contact Us - Contact details, social links, and message form

## Main Features

- Modern orange-themed portfolio design
- Dark and light mode toggle
- Responsive layout for desktop and mobile devices
- Animated typing effect on the homepage
- Project cards with relevant icon and service visuals
- Contact section with WhatsApp, email, Facebook, Instagram, LinkedIn, and GitHub links
- Floating back-to-top button
- Working contact form that opens the user’s email client

## How to Run the Website

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Start a local server, for example:
   - `cd c:\Users\HAST\Documents\potfolio`
   - `py -m http.server 8000`
4. Open `http://localhost:8000` in your browser.
